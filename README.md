# discord-wlf

Личный экспериментальный Discord-бот, в котором я собираю небольшие инструменты для работы с изображениями, настройками пользователя и повседневными действиями в Discord.

Проект развивается как полигон для идей: часть функций сделана ради практической пользы, часть — чтобы попробовать новые подходы, библиотеки и интеграции.

## Что умеет бот

### Работа с изображениями

- конвертация изображений в PNG;
- конвертация изображений в GIF;
- применение простых фильтров;
- создание bubble-изображений;
- создание bubble-изображений с автоматическим определением позиции через модель из [TargetCloudDetect](https://github.com/Whiox/TargetCloudDetect).

Команды доступны как slash-команды, а часть действий можно запускать через контекстное меню сообщения с вложением.

### Пользовательские настройки

- настройка цвета embed-ответов;
- выбор публичного или приватного режима ответов;
- сохранение пользовательских настроек в базе данных;
- просмотр информации о пользователе Discord.

### Вспомогательные команды

- проверка задержки бота и базы данных;
- исправление текста, набранного в неправильной раскладке;
- встроенная справка по командам.

### Метрики

В проект добавлен экспорт метрик для Prometheus:

- количество выполнений команд;
- количество ошибок команд;
- количество обращений к базе данных.

Для локального мониторинга можно поднять Prometheus и Grafana через Docker Compose.

## Команды

### Basic

| Команда | Описание |
| --- | --- |
| `/help` | Показывает справку по командам. |
| `/user_info` | Показывает информацию о пользователе Discord. |
| `/ping` | Проверяет задержку бота и соединение с базой данных. |
| `/color` | Меняет цвет embed-сообщений. |
| `/mode` | Переключает режим ответов бота. |

### Converter

| Команда | Описание |
| --- | --- |
| `/png` | Конвертирует изображение в PNG. |
| `/gif` | Конвертирует изображение в GIF. |
| `/filter` | Применяет фильтр к изображению. |
| `/bubble` | Создаёт bubble-изображение с ручными параметрами. |
| `/bubble_ai` | Создаёт bubble-изображение с автоматическим определением позиции. |

### Helper

| Команда | Описание |
| --- | --- |
| `/relanguage` | Исправляет текст, набранный в неправильной раскладке. |

## Настройка

Создайте `.env` на основе `.example.env`:

```env
# # Bot settings
TOKEN=

DB_URI=
DB_NAME=
DB_HOST=
DB_PORT=
DB_USER=
DB_PASSWORD=
DB_SSL=REQUIRED

COLLECT_METRICS=True
HTTP_SERVER_PORT=8081

# # Compose settings
# COLLECT_METRICS should be enabled too
COMPOSE_PROFILES=monitoring

# # For launch without grafana/prometheus
#COMPOSE_PROFILES=
```

## Локальный запуск

Установить зависимости:

```bash
pip install -r requirements.txt
```

Запустить бота:

```bash
python main.py
```

## Запуск через Docker Compose

Запуск:

```bash
docker compose up --build
```

Настройка запускаемых модулей производиться в .env, см. .example.env

После запуска:

- Prometheus: [http://localhost:9090](http://localhost:9090)
- Grafana: [http://localhost:3000](http://localhost:3000)
