# discord-wlf

Личный экспериментальный Discord-бот, в котором я реализую интересные
и потенциально полезные мне функции.

Проект объединяет обработку изображений, собственную нейросеть,
пользовательские настройки Discord и небольшие повседневные инструменты.

> Бот активно развивается. Некоторые части были написаны в процессе
> обучения и постепенно перерабатываются.

## Главная особенность

Команда `/reply_smart` использует мою библиотеку
[TargetCloudDetect](https://github.com/Whiox/TargetCloudDetect)
с собственной нейросетью на Keras.

Модель анализирует загруженное изображение и автоматически определяет,
как расположить шаблон reply-картинки. В обычной команде `/reply`
параметры задаются вручную.

## Возможности

- конвертация изображений в PNG и GIF;
- создание reply-картинок;
- автоматическая обработка изображений нейросетью;
- исправление текста, набранного в неверной раскладке;
- настройка цвета ответов;
- выбор публичного или приватного режима;
- просмотр информации о пользователях Discord;
- slash-команды и команды контекстного меню;
- использование на серверах, в личных сообщениях и приватных каналах.

## Интеграция с War Thunder

Ранее бот получал статистику игроков и сведения о полках через API
ThunderInsights.

Сейчас эти команды не работают, поскольку внешний API был закрыт.
Реализация оставлена в репозитории как часть истории проекта.
